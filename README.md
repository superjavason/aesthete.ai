# 品味的觉醒：AI时代的审美方法论

> 在一个算法替我们选择的时代，品味是最后的自由意志。

## 书籍定位

- **核心主题：** 在AI与算法主导的时代，如何系统性培养判断力、审美主权与人文品味
- **写作风格：** 学术深度 + 人文关怀 + 技术洞察，兼具哲学思考与实践指导
- **目标读者：** 关注审美、希望在数字时代保持独立思考的知识工作者、创意从业者

## 如何使用这本书

**如果你是初学者**：从第一部分开始，每两天读一章，按顺序推进。每章末尾的练习不要跳过——品味是练出来的，不是读出来的。

**如果你是创意工作者**：可以直接跳到你的专业领域（媒体、UI/UX、包装、建筑、摄影），但建议回头补读第一部分和第二部分的训练模块，它们提供的是跨领域的底层审美能力。

**如果你对AI感兴趣**：第三部分是核心，但请先读第一部分建立认知基础——没有审美判断力，AI工具只会放大你的平庸。

**如果你只有一周时间**：读第1、8、15、30、45、52、81、156章——它们构成全书的骨架。

## 关于这本书的品味观

我们不相信存在唯一正确的审美标准。但我们相信存在更好的"看"的方式。

品味不是区分高雅与低俗的标签，而是感知力、判断力与表达力的三位一体。它让你在嘈杂中听见微弱的好声音，在泛滥中认出稀缺的真东西，在迷茫中找到属于自己的审美坐标。

在算法为每个人量身定制信息茧房的今天，培养品味就是培养自由。

> 美不是答案。美是一种提问的方式。
